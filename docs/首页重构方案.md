# 首页重构方案：从功能入口 → 产品展示厅

> 背景：所有功能已收进侧边栏，首页不再承担"入口"职责。
> 新定位：**产品展示厅** —— 3 秒内让新用户看懂"这是什么、能给我什么、下一步做什么"，
> 同时让老用户回来有"数据感、成就感、继续感"。

---

## 一、定位转变（为什么这样想）

| 维度 | 旧首页 | 新首页 |
|---|---|---|
| 职责 | 功能入口堆叠（按钮） | 产品价值展示（成果演示） |
| 新用户 3 秒 | 看不懂，点哪里都行 | 看懂价值 + 有清晰下一步 |
| 老用户 | 扫一眼就走 | 有数据/成就/继续的钩子 |
| 信息层级 | 一屏塞满 | Hero → 演示 → 数据 → 激励 逐层递进 |

**核心逻辑：Show, don't tell。** 与其说"我们有三大考核"，不如把考核的**真实效果**摆出来：一道真实理论题、一段代码实战题、一段面试对话——让用户"看见"自己即将体验的东西。

---

## 二、用户分层思考（PM × 运营）

### 1. 新用户（第一屏 ≤5 秒）
必须回答三个问题：
- **这是什么？** → Hero 一句话价值主张 + 副标题
- **对我有什么用？** → 功能 Showcase 用"真实成果"演示
- **现在做什么？** → 唯一主 CTA（快速开始）+ 次 CTA（导入资料）

### 2. 老用户（高频回访）
钩子：
- **数据感**：能力雷达图实时更新（已考核时展示真实数据）
- **成就感**：等级 + 经验进度条 + 徽章数 + 连击
- **继续感**：最近动态（最近 3 次考核/面试）+ 下一步推荐（复用快速开始逻辑）

### 3. 游客/犹豫者（装好没配 Key）
- 首页不因"未配置 LLM"而灰一片：Showcase 用**静态示例**演示效果（不依赖 LLM），
  只在真正要开始考核时才提示配置 → 降低首屏挫败感

## 四、模块详细设计

### ① Hero 区
- **主标题**：AI 岗位能力试炼（保留赛博大字 + 霓虹光晕）
- **价值主张**（3 点徽章式）：⚡ AI 自动出题（导入即生成题库）· 🎤 真实面试模拟（AI 面试官严格追问）· 📊 数据化成长（十维画像 + 岗位匹配）
- **CTA**：主「快速开始」（火箭，去快速开始页）；次「导入我的资料」（幽灵按钮）
- **氛围**：右侧小号雷达图动画（用示例数据 + drawRadarProfile 跑一次，作为产品演示而非个人数据）——让新用户第一眼就"看到"产品核心视觉

### ② 功能 Showcase（重点，Show don't tell）
每张卡 = 霓虹图标 + 名称 + 一句话 + **真实内容预览**：

| 卡 | 预览内容（静态示例，不依赖 LLM/数据） |
|---|---|
| 理论考核 | 一道示例选择题：题干 + 2-3 个选项 + 题型 chip（模拟"作答界面"） |
| 实战考核 | 一段代码片段（mono 字体 + 行号样式）+ 问题行（"这段代码的输出是？"） |
| 面试考核 | 面试对话气泡演示：面试官问 → 候选人答 → 面试官追问（静态 2-3 轮） |
| 能力画像 | 迷你维度条 5-6 条（示例值，渐变进度条）+ "十维雷达 + 岗位匹配" 说明 |

- 卡片 hover 抬升 + 霓虹描边；点击 → 对应考核介绍页（复用 showExamIntro）
- **示例数据**：内置常量（EXAMPLES），不读用户数据 → 新用户无数据也能看到完整演示

### ③ 我的数据（真实数据区）
- **有数据**：能力雷达图（真实）+ 最近动态 3 条（时间 + 模式 + 分数/岗位，点击可进历史）
- **无数据**：引导空态——"完成任意一次考核，这里将生成你的能力雷达图" + CTA
- 最近动态数据源：state.history + state.interviewLogs（取最近 3 条合并排序）

### ④ 成长激励条
- 等级经验进度条（现有 XP 数据）+ 距离下一级还需 XP
- 连击天数 · 徽章数 · 下一步推荐（复用 guideNextStepId 文案）
- 运营向：让老用户每次回来都有"再进一步"的目标感

---

## 五、运营向细节

1. **首屏零挫败**：Showcase 全部用静态示例，未配 Key / 无资料也能完整展示 → 不吓跑游客
2. **唯一的下一步**：每个区域只有一个主动作，避免选择困难
3. **数据钩子**：雷达图从"演示动画"平滑过渡到"真实数据"（有数据后 ③ 区替换 ① 区的小动画）——用户感知"我的数据在生长"
4. **成就可见**：底部激励条常驻，成就/等级随时可见
