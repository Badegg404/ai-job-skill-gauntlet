# UI 优化方案：借鉴 ModelScope 重构信息架构与组件规范

> 参考对象：https://www.modelscope.cn/my/overview（魔搭社区 · 个人中心总览）
> 现状：赛博朋克 HUD 风（纯黑底 + 霓虹青/品红 + 网格/扫描线/粒子 + Orbitron 字体）
> 本文先给「现状问题诊断 + ModelScope 可借鉴清单」，再给**三条方向**与**逐模块改动方案**，请先拍板方向再实施。

---

## 一、现状诊断（赛博 HUD 风的问题）

| 维度 | 现状 | 问题 |
|---|---|---|
| 信息架构 | 无侧边导航；所有功能入口堆在首页一排按钮 + 顶栏 | 页面间靠按钮跳转，层级深；功能多了入口找不到 |
| 顶栏 | exam-topbar：logo + 6 个 gs-item 小字数字 | 数据密集、字号小（11px），可读性差 |
| 首页 | hero 大标题 + 三张 mode-card + 画像卡 | 无数据看板；hero 占位大而空；信息密度低 |
| 配色 | 纯黑底 + 霓虹青/品红/紫大面积使用 | 长时间使用疲劳；霓虹用于所有强调导致无层级 |
| 背景动效 | 网格线 + 扫描光带 + 粒子连线 | 分散注意力；与"严肃考核"场景气质不符 |
| 组件 | 无统一间距系统/规范，各页内联样式多 | 风格不统一，改版成本高 |

## 二、ModelScope /my/overview 可借鉴清单（已核实为 React+AntD 企业风）

| ModelScope 元素 | 具体表现 | 对咱们的借鉴价值 |
|---|---|---|
| 顶部 Header | Logo + 全局搜索 + 通知 + 用户头像下拉，常驻 | 把 logo + 搜索 + 用户区固定顶部，替代纯 gamestat |
| 左侧导航 | 个人菜单（概览/模型/数据集/空间/收藏/设置），图标+文字，当前项高亮 | 我们的功能正好适配：首页/导入/目录/考核/面试/画像/历史/诊断 |
| 统计看板 | 顶部一排大数字卡片：图标 + 大数字 + 标题 + 趋势 | 首页顶部放 XP/等级/考核次数/徽章/连击/导入数的指标卡 |
| 内容卡片 | 圆角卡片 + 轻阴影 + 图标标题 + 列表项，留白充足 | 统一 card 规范，取代霓虹重边框 |
| 信息层级 | 主色蓝（#276EF1 系）+ 灰阶文字三级 + 白底 | 单一主色 + 灰阶层级，霓虹只用于成就时刻 |
| 组件克制 | 按钮/标签/徽章/表格/进度条全部规范统一 | 建立 btn/tag/chip/progress 统一规范 |
| 导航即地图 | 功能归类清晰，点导航直达 | 减少首页按钮堆叠 |

> 注意：ModelScope 是"模型社区网站"，我们是"学习考核桌面应用"——**照搬浅色企业风会丢失游戏化激励**（XP/徽章/连击/成就视觉）。方案倾向「保留赛博基因 × 借鉴其信息架构与克制」，见方向三。

## 三、方向选择（请拍板）

- **方向 A：浅色企业风**（接近 ModelScope）——白底 + 蓝主色 + 左侧导航 + 数据看板，彻底放弃赛博。风险：与游戏化激励的契合度下降，但最接近参考站。
- **方向 B：保留赛博，仅做微调**——小改配色/间距/卡片，不动架构。风险：解决不了"入口分散/顶栏拥挤"的结构问题。
- **方向 C（推荐）：赛博基因 × ModelScope 架构**——深色但去纯黑（深蓝灰底）、霓虹降噪只做强调、引入左侧导航 + 顶部 Header + 首页数据看板 + 组件规范统一。既解决结构问题，又保留"AI 能力试炼"的科技游戏感。

以下按**方向 C** 给出详细方案（A/B 可在此基础上调整）。

## 四、逐模块改动方案（方向 C）

### 4.1 布局：新增左侧导航 + 常驻顶部 Header（借鉴 ModelScope 框架）

```
┌──────────────┬─────────────────────────────────────┐
│  LOGO 导航栏  │  Header：搜索框 …  👤 昵称 · 等级 · 设置 │  ← 顶部（替代纯 gamestat）
├──────────────┼─────────────────────────────────────┤
│  🏠 首页      │                                     │
│  📥 导入      │       主内容区（max-width 容器）        │
│  🗂️ 资料目录  │       数据看板 / 功能页                 │
│  📘 理论考核  │                                     │
│  🛠️ 实战考核  │                                     │
│  💼 面试      │                                     │
│  🧬 能力画像  │                                     │
│  📈 历史记录  │                                     │
│  📕 错题本    │                                     │
│  🔍 诊断日志  │                                     │
└──────────────┴─────────────────────────────────────┘
```

- 新增 `.app-sidebar`（左侧 200-220px）：图标 + 文字菜单，当前项高亮（主色左边条 + 底色）
- 顶栏 `exam-topbar` 改造：左 logo，中全局搜索（搜目录/题目/历史，回车直达），右用户区（昵称 + 等级 chip + ⚙️）
- 考核/面试过程中可隐藏侧栏（全屏专注），其余页面常驻
- 实现：exam.html 加 sidebar 容器，exam.js 加 `showView(key)` 路由分发（替代现在各处 goHome/跳转），改造量集中在导航层

### 4.2 首页 → 数据看板（借鉴 /my/overview 统计卡片）

- 顶部**统计卡片行**（5-6 张）：XP / 等级称号 / 考核次数 / 徽章数 / 连击纪录 / 导入资料数
  - 每张卡：大数字（Orbitron 保留）+ 标题 + 小图标；hover 轻微抬升
  - 替换现在顶栏的 6 个 gs-item 小字（gs-item 可保留在考核页内）
- 三大考核入口（mode-card）：去霓虹重发光，改**干净卡片**：图标 + 标题 + 一句话描述 + 状态 tag（可用/需 LLM/题量不足置灰），主色渐变作顶部细条点缀
- 新增**最近动态**列表（借鉴 ModelScope 最近动态）：最近 5 次考核/面试记录（时间 + 模式 + 分数），空态给引导
- 能力画像雷达图保留，但卡片化 + 标题"🧬 综合能力画像"（现状已有）

### 4.3 配色系统（保留赛博基因，降噪）

```css
:root {
  /* 背景：纯黑 → 深蓝灰（降低长时间使用疲劳） */
  --bg-0: #0b0f17;
  --bg-1: #0f1520;
  --bg-2: #141c2b;
  /* 卡片：浅色玻璃感（替代 rgba 白 0.03 的纯透明） */
  --card: rgba(255, 255, 255, 0.045);
  --card-hover: rgba(255, 255, 255, 0.07);
  --border: rgba(148, 163, 184, 0.14);        /* 冷灰边框替代青色边框 */
  /* 主色：霓虹青降为品牌点缀，新增中性强调色 */
  --accent: #22d3ee;                          /* 降饱和 cyan */
  --accent-2: #e879f9;                        /* 柔和品红（仅强调） */
  --accent-3: #818cf8;                        /* 靛蓝（替代刺眼紫） */
  /* 成功/警告/危险：语义色，保持可读 */
  --ok: #34d399; --warn: #fbbf24; --danger: #f87171;
  /* 文字层级 */
  --text-0: #eef2f7; --text-1: #aab6c6; --text-2: #6b7a8f;
  /* 统一圆角/阴影 */
  --radius: 12px; --shadow: 0 1px 2px rgba(0,0,0,0.4), 0 8px 24px rgba(0,0,0,0.35);
}
```

- 网格/扫描线/粒子：默认**关闭或极淡**（body::before/after 保留但 opacity 0.02，或设置里加开关）
- 霓虹 glow（--glow）仅保留给：成就时刻（徽章弹出/连击/等级提升），日常 UI 不用

### 4.4 组件规范统一（借鉴 AntD 克制）

- **按钮**：`--btn-h` 40px 统一；primary（主色渐变）/ ghost（描边）/ danger（红）；圆角 10px；hover 过渡 0.15s
- **标签 chip**：题型（判断/选择/填空/实战/面试）+ 维度 + 状态统一小 chip（现在 exam-q-type 已有，统一尺寸/圆角）
- **卡片**：统一 padding 20px、radius 12px、hover 抬升 2px + 阴影；去霓虹边框
- **间距**：8px 网格体系（--sp-1..--sp-8），页面容器 max-width 1100px 居中
- **进度条**：考核进度/导入进度统一（现在已有 exam-progress-fill，去掉发光）
- **Modal/Toast**：统一样式（现在已单例，微调圆角/阴影）

### 4.5 考核页 / 面试间微调

- 考核题卡：题号 + 题型 chip + 来源 + 难度，进度条加"第 X/N 题"文字（现状有部分，统一化）
- 面试间（聊天式）：借鉴社区对话列表——头像 + 气泡 + 时间戳 + 输入区固定底部 + 发送按钮，弱化霓虹边框，答好/答差用语义色（ok/warn）而非霓虹
- 结果页：成绩大数字 + 星级 + 维度条，用语义色区分通过/未通过

### 4.6 远期（可选）

- **双主题**：CSS 变量已集中，可加"赛博暗 / 清爽亮"切换（亮色即方向 A 的 ModelScope 浅色风），localStorage 记忆——成本低收益高
- 中文字体：引入本地"阿里巴巴普惠体"或继续 PingFang

## 七、图标系统（已实施 2026-08-24）

**背景**：用户反馈"图标元素特别土，尤其是很多 emoji 图标"。已建立本地 SVG 图标系统替换控件类 emoji（内容性 emoji 保留）。

**实现**：
- 新增 `web/icons.js`：45 个 Lucide 线框图标（ISC 协议，stroke="currentColor"），内联 SVG 字符串
- `exam.js` 新增 `icon(name, cls)` 渲染辅助：返回 `<svg class="svg-icon">`，CSS 控制尺寸/颜色/发光（.svg-icon / .lg / .xl / .xxl）
- `style.css` 新增 .svg-icon 系列样式（currentColor 继承、drop-shadow 赛博发光）

**已替换范围**（控件 emoji → SVG）：
- 首页：三大考核卡（book-open/wrench/briefcase）、主按钮（upload/folder/radar/settings）、底部按钮组（award/history/briefcase/bookmark/terminal）、空态、画像标题、提示条
- 设置页：标题（settings/user/robot/trash-2）、保存/测试/读取按钮
- 导入页：标题（upload）、导入文件夹/文件按钮
- 资料目录页：标题、新建/管理/删除/改名、理论/实战/补出题按钮、空态
- 各功能页标题：面试/画像/增长点/岗位匹配/错题回顾/评估/成就墙/学习历史/面试记录/诊断日志

**保留的 emoji**（内容性/情绪/成就）：🎉🏆🔥⭐🧠💡📚🚀📝👤 等——用于成就庆祝、教学文案、情绪表达。

**后续可继续替换**：考核题卡状态提示（⚠️✅❌🤖 高频）、面试对话气泡、toast/modal 图标——按需铺开。

## 八、布局优化方向（待拍板，保留赛博基因）

借鉴 ModelScope 信息架构，但保持霓虹风格（不是浅色企业风）：

1. **常驻左侧导航**（推荐）：首页/导入/目录/理论/实战/面试/画像/历史/错题本/诊断 → 侧栏图标+文字，当前项霓虹高亮；考核/面试中可收起全屏。解决"功能入口堆在首页一排按钮"
2. **顶栏优化**：logo + 全局搜索（搜目录/题/历史）+ 用户区（昵称/等级/设置）；gamestat 保留但字号调大
3. **首页数据看板**：顶部统计卡片行（XP/等级/考核次数/徽章/连击/导入数，大数字+图标，Orbitron 数字），替代顶栏 6 个小字；下方"最近动态"列表
4. **背景动效降噪**：网格/扫描线/粒子默认关闭或极淡（设置里可开），霓虹 glow 只留给成就时刻

以上 4 项均为可选，拍板后实施（P1 布局骨架 → P2 首页看板 → P3 动效设置项）。
