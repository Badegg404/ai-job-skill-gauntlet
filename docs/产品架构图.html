2. 2.1 导入出题（资料 → 章节目录 → 题库）

sequenceDiagram
    participant U as 用户
    participant E as 前端 exam.js
    participant S as server.py
    participant P as pipeline/parser
    participant L as LLM API

    U->>E: 拖拽文件/文件夹
    E->>S: POST /api/import-batch（多份 md）
    S->>P: 解析资料（note_parser：章节/概念/难点/测验）
    P->>S: 返回目录骨架 + 素材
    S-->>E: dir + course（含资料自带题）
    loop 理论 16 + 实战 10（首轮 + 最多 2 轮补足）
        E->>E: browserLLMGenerate（llmJSON 约束层）
        E->>L: 出题请求（prompts.js 模板 + 格式约束）
        L-->>E: JSON 题（scoring.js 解析/归一化/校验）
        E->>E: hangQ 去重挂库 → data.course.quiz
    end
    E->>S: POST /api/course-save（回写目录 + 课程库）
    E->>L: generateJobQuestions（岗位面试题提炼）
    E->>E: 导入完成（不足降级可用 + 补出题入口）
    E->>LG: import.done 日志

3. 2.2 考核（组卷 → 答题 → 判分 → 画像）

sequenceDiagram
    participant U as 用户
    participant E as 前端 exam.js
    participant S as server.py
    participant L as LLM API

    U->>E: 进入理论/实战考核
    E->>S: GET /api/dirs（聚合全部目录题库）
    S-->>E: 目录 + 题量（theoryCount/practicalCount）
    E->>E: 组卷：llmPickQuestions（LLM 挑题）
    E->>L: 组卷请求（picks 数组）
    L-->>E: picks → 试卷；失败走 adaptivePick 程序兜底
    loop 逐题作答
        U->>E: 提交答案
        alt 客观题（选择/判断）
            E->>E: judgeAnswer 程序判分（零误差）
        else 语义判分（代码/阅读/填空/问答）
            E->>L: llmGrade*（统一 llmJSON）
            L-->>E: score/correct → 渲染结果
        end
        E->>E: 能力计分/连击/错题本
    end
    E->>E: showResult（成绩 + 能力得分率）
    E->>E: saveState → profile.json（能力画像累积）
    E->>S: POST /api/profile-save（clientTs 竞态防护）

4. 2.3 面试（StateGraph 八节点）

sequenceDiagram
    participant U as 用户
    participant E as 前端 InterviewGraph
    participant L as LLM API

    U->>E: 选择岗位 → startJobInterview
    E->>E: begin("iv") sessionId + 构建上下文（资料采样）
    loop 每轮（maxRounds）
        E->>L: ask 出题（岗位+资料+已问过去重）
        L-->>E: 题目（题形：场景/问答/代码/选择）
        U->>E: 作答
        E->>E: record（弱回答正则检测）
        alt 连续原题弱答 ≥3
            E->>E: fail（提前终止）
        else
            E->>L: judge 评估（followup/advance/judged）
            L-->>E: 结果
            alt 需要追问（预算递减）
                E->>L: 追问
                L-->>E: 追问文案
            else 答好
                E->>E: advance（下一题）
            end
        end
    end
    E->>L: finishInterview 综合评分
    L-->>E: totalScore + 维度点评
    E->>E: interviewLogs 存档 → profile.json
